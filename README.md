## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

This writes a single line (115 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Pure Python standard library, no dependencies, deterministic: two runs produce byte-identical output.
